# Twelve additions: curation and browser admission

Chase H.Q. and APB were requested. The ten companion choices fill genres and control styles missing from the existing 51 without substituting console editions. Shinobi replaces Ghouls ’n Ghosts at the user’s request; Qix replaces Paperboy after an observed browser rendering failure.

| Cabinet | Why it belongs | Original edition |
| --- | --- | --- |
| Chase H.Q. | Requested police pursuit racer; preserve steering, brake, turbo, gear and criminal-car ramming. | World |
| APB: All Points Bulletin | Requested Atari police patrol; preserve the continuous wheel, pedal, siren and arrest quotas. | Revision 7 |
| Golden Axe | Adds fantasyco-op, mounts, magic and camp scenes distinct from the existing urban brawlers. | US · set 6 |
| R-Type | Adds the chargebeam and detachableForce branch of horizontal shooting. | World |
| Gradius | Adds the capsule-selection upgrade bar and classic horizontal stage design. | Japan · ROM board |
| Arkanoid | Adds paddle-based brickbreaking with original capsule powerups. | World · older |
| Marble Madness | Adds two-trackball isometric skill racing. | Set 1 |
| Tetris | Adds classic fallingblock play and simultaneous independent wells. | Atari arcade · set 1 |
| Shinobi | User-requested replacement for Ghouls nGhosts; rescue missions, ninja magic and bonus rounds. | Set 6 · original System 16A |
| Street Fighter Alpha 2 | Adds Alpha Counters, CustomCombos and the Alpha-era arcade roster. | Europe · 960229 |
| Alien vs. Predator | Adds three-player sci-fi combat, ammo and distinct human/Predator combat systems. | Europe · 940520 |
| Qix | Adds territory-drawing puzzles; selected after Paperboy failed its browser rendering gate. | Revision 2 |

Primary references: [Sega Golden Axe arcade history](https://www.sega.jp/history/arcade/product/9255/), [Konami Gradius history](https://www.konami.com/games/jp/ja/products/dl_ps4_gradius_arch/), [Capcom Alpha 2 history](https://captown.capcom.com/en/classic_games/41).
